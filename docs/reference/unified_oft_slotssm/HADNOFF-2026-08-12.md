# Unified OFT + SlotSSM：book→caddy 恢复工作交接（2026-08-12）

## 0. 目标与边界

当前主目标是在 LIBERO-Plus 的 `Robot Initial States` 扰动下，提升
OpenVLA-OFT+ 在下述语义任务上的完成率：

```text
STUDY_SCENE1_pick_up_the_book_and_place_it_in_the_back_compartment_of_the_caddy
```

- task id：`491..524`，共 34 个官方初始状态，每个用 `episode_id=0`。
- 冻结 OFT+ baseline：`11/34 = 32.35%` 成功。
- 不能把使用物体位姿、接触、固定 target anchor 或 FSM 在线控制的结果称为端到端学习式结果。
- 可以把这些 privileged 信息用于 **离线 teacher 数据生成/标签**，但线上模型输入只能是：双相机 RGB、语言、机器人 proprio、已执行动作历史、OFT hidden 和 SlotSSM state。

用户当前的明确偏好：希望最终是端到端恢复；容许任务内过拟合，只要该语义任务整体成功率超过原始 OFT+，但必须如实说明哪些结果带 FSM/anchor，哪些是纯神经。

## 1. 当前架构

线上 normal 路径：官方 OpenVLA-OFT+ action 路径（保持官方预处理、8-action chunk）。

恢复路径：

```text
dual RGB + language -> frozen OFT+ action-token hidden
                         + frozen SlotAttention / causal SlotSSM state
                         + proprio + previous executed action
                       -> learned gate (NORMAL/RECOVERY)
                       -> learned 5-way approach-mode selector
                       -> mode-conditioned neural recovery action head
                       -> one action per closed-loop recovery step
```

五个 approach mode 是 teacher 程序蒸馏出的离散横向接近方式：

| mode id | teacher candidate |
|---:|---|
| 0 | `fsm_xyp0_p0` |
| 1 | `fsm_xym25_p0` |
| 2 | `fsm_xyp0_m25` |
| 3 | `fsm_xyp0_p25` |
| 4 | `fsm_xyp25_p0` |

当前纯神经 runner 使用 candidate verifier **只作为 learned mode selector**；恢复动作由 adapter 的 `recovery_actions` 输出。不能启用 `--recovery-geometry-controller`、`--recovery-anchor-fsm` 或 `--recovery-target-anchor`。

## 2. 最重要的已修复问题

### 训练—部署 OFT hidden mismatch（已修）

此前离线特征提取使用：

```text
agentview[::-1, ::-1] / wrist[::-1, ::-1] -> center_crop_resize -> model.predict_action
```

但在线恢复/gate/head 曾读取官方 evaluator preprocessing 产生的 hidden；同时恢复刚触发时还可能沿用上一段 normal chunk 的旧 hidden。结果是离线 geometry 看起来准确、在线几何/动作严重失真。

`scripts/run_oft_slotssm_unified_episode.py` 现已加入 `recovery_feature_query()`：

1. normal 的实际动作仍完全来自 official OFT+ path；
2. gate/recovery head 的 hidden 改为与 frozen training features 相同的 `input_` convention；
3. 从 NORMAL 切入 RECOVERY 时强制用当前 observation 刷新 hidden。

这是目前纯神经恢复第一次成功的关键修复。修改已通过：

```bash
python -m py_compile scripts/run_oft_slotssm_unified_episode.py
```

## 9. 已知限制与正确表述

- gate 当前仅在同源 window 上验证，不是 reportable/general failure detector。
- candidate verifier 当前优化的是 teacher verified regrasp，不等价于 task completion；501/504/511 的分析证明这两者不同。
- 501 单条成功是重要 end-to-end proof-of-closure，但不是泛化成功率结论。
- 28/34 的 FSM 结果是很强工程/teacher upper baseline，不是端到端 SlotSSM 成功率。
- 正确的研究故事是：用 OFT hidden + temporally causal SlotSSM + proprio/history，学习何时局部介入、选择何种恢复 mode、再用 state-conditioned neural action closed loop 执行；teacher pose/contact 只用来生成 offline supervision。

## 11. 2026-08-13 后续实验：完整 teacher、on-policy DAgger 与可复现性

本节记录 8 月 12 日夜间至 13 日凌晨完成的工作。用户已明确允许在固定
34 条状态上训练/测试重合；但线上策略仍必须保持纯神经输入边界（RGB、wrist
RGB、语言、proprio、动作历史），不能读 caddy/book anchor、接触或 FSM 动作。

### 11.1 已完成且可复用的数据链路

- 新增 `collect_book_placement_search.py`：从 verified-lift MuJoCo snapshot 搜索
  transport-lift → transport → place → open → retreat。以 `env.done` 为唯一完成标签。
- task501、task504、task511 的 `fsm_xyp25_p0` lift snapshot 均找到了成功的完整

- `build_book_completion_manifest.py` 与 `precompute_book_regrasp_v2_features.py`

### 11.2 不应推广的结果

- v12/v13/v14 将 completion teacher 混入 recovery head，离线 completion loss
  可降至约 0.18，却破坏 task501 原有的抓取闭环；不要推广。
- v16/v18 将 504/511 on-policy DAgger 与 v8 数据混合，504 线上仍失败。
- v19 对 task501 与一次 task511 成功纯神经轨迹作 self-distillation，仍未保住
  task501。
- v21 使用 phase experts + learned argmax hard routing，只训练原始三条
  xyp25 regrasp teacher（32 个 window）；离线 action loss 约 0.023，但 task504
  线上仍失败。`--neural-hard-phase-routing` 是纯神经模式（阶段来自网络 argmax），
  但目前不是成功版本。

核心经验：离线 MSE/teacher-routed MSE 的下降不能替代完整闭环成功；运输教师和
FSM teacher 的动作分布均可能把接触敏感的 v8 路径拉离成功流形。

- v8：`$BASE/neural-geometry-v8-aux/recovery-head-v8/adapter_best.safetensors`。
- task501 已在 2026-08-13 复跑第二次成功，均为 398 frames；两次保存的决策动作

### 11.4 下一步优先级

1. 保留 v8 作为唯一候选基线，不要再以单一 action-head 微调替代它。
2. 对 task504/511 做多轮 on-policy DAgger，但需要一个**不改写 v8 前半段动作**的

3. 每一候选先跑 501/504/511；只有三个任务中出现可重复的端到端增益，才扩展到
   全部 34 条状态。

## 12. 2026-08-13：时域选择性的纯神经残差（v23）

### 16.3 已定位的模型根因与结构修正

- 对比 onset 动作可见，495/508 的 archived teacher 在恢复前五步先执行纯 Z 方向上抬

  输入 recovery **action** path。于是 action head 无法用因果动作历史区分“刚进入
  recovery 的 backoff/lift”与“已完成上抬的 align/descend”，容易把多个 teacher phase
  平均为一个起点动作。

  不变，旧 checkpoint 在首次加载时 recovery 输出也严格保持不变。训练脚本允许该新增
