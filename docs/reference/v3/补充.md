把当前 recovery 分支改成 **failure-conditioned action correction**，核心修改如下：

1. **Normal action 保持不变**

   * OpenVLA-OFT 冻结并输出正常动作：
     [
     A_n^N=\pi_N(O_n)
     ]
   * 正常状态直接执行 (A_n^N)。

2. **增加 failure-effect 表示**

   * SlotSSM 继续维护对象状态 (S_{n-1},S_n)。
   * 利用上一动作构造：
     [
     E_n=f_E(S_{n-1},S_n,A_{n-1},p_n)
     ]
   * (E_n) 表示“上一动作执行后，对象实际发生了什么异常变化”。

3. **Failure Gate 改为基于 (E_n)**
   [
   g_n=G(E_n,S_n,h_n)
   ]

   * (h_n)：OFT feature。
   * (g_n>\tau) 才进入 recovery。

4. **Recovery Head 不再只做**
   [
   CrossAttn(Q_n,S_n,S_n)
   ]
   而是让 query 同时依赖 **正常动作和 failure effect**：
   [
   Q_n^R=f_Q(h_n,A_n^N,E_n,p_n)
   ]
   [
   C_n^R=CrossAttn(Q_n^R,S_n,S_n)
   ]

5. **Recovery Head 输出 corrected action**
   [
   A_n^R=R(C_n^R,E_n,A_n^N,p_n)
   ]
   即明确让 recovery 学习：

   > 根据 failure、当前对象状态以及 OFT 原本准备执行的动作，生成修正后的动作。

6. **最终执行**
   [
   A_n^{exec}=
   \begin{cases}
   A_n^N,&g_n\le\tau\
   A_n^R,&g_n>\tau
   \end{cases}
   ]

7. **训练监督**

   * recovery teacher/FSM 给出成功恢复动作 (A_n^{R*})；
   * Recovery Head 使用 L1：
     [
     L_{rec}=|A_n^R-A_n^{R*}|_1
     ]
   * SlotSSM 原有 future-slot prediction loss 保留，用于维持 action-aware object representation。

核心思想从：

**Slot → 另一套 action policy**

改成：

**Failure effect + object state + nominal action → corrected recovery action**

这样 recovery 和 normal policy 的职责明确区分：OFT 负责正常任务推进，recovery 只负责失败后的 corrective intervention。
