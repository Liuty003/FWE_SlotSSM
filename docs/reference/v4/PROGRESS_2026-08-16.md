# V4.2 当前进度（2026-08-16）

## 已经落地

- V4.2 主模型已独立实现：OFT token Slot Attention、RGB-D robot-frame 3D relations、以 action hidden 为 query 的 cross-attention，以及共享 `C_t` 的 gate / recovery adapter。
- OFT backbone、proprio projector 和原 action decoder 全冻结；恢复 hidden 仍由同一个 OFT decoder 解码，hard gate 未触发时逐元素精确旁路。
- Stage 1 的 Slot 训练是 V4 自己的实现，没有复用 V1--V3 的 SlotSSM/world-model 代码。训练时使用 simulator instance mask，但在线不读取 instance mask。
- Slot mask supervision 已改为 Hungarian one-to-one matching，禁止多个物体复用同一 slot。
- V4 RGB-D collector、feature freezer、merge/split、两阶段 trainer、离线 evaluator 和 paired online runner 已贯通。
- feature / decoder provenance 已强制校验 action-head 与 proprio-projector SHA-256。

## 本轮修掉的两个静默错误

1. 旧 feature freezer 把 nominal action 归一化，却把 physical recovery target 直接交给 frozen decoder loss。现在 recovery target 使用 checkpoint 的同一套 action statistics 转换到 decoder coordinates。
2. 旧验证代码按 batch 平均 recovery loss，纯 normal batch 被当成 recovery loss 为零，导致日志虚低。现在 gate、slot 和 recovery 都按各自有效样本数聚合，并分别保存 best-total / best-gate / best-recovery checkpoint。

旧 Book Stage 2 checkpoint 因第 1 个错误不再作为有效 V4.2 结果。

## 当前数据和训练结果

- Book fixed feature：198 decisions、9 physical sources；147 normal、51 recovery，其中只有 3 个 recovery sources。
- source-stratified split：train 132 rows / 6 sources，validation 66 rows / 3 sources；validation 含一个完全留出的 recovery source。
- Stage 1 Hungarian Slot best validation loss：2.7564（step 600）。
- Stage 2 当前最佳：gate label smoothing 0.10，step 600。
- 留出集：normal probability mean 0.0482，recovery probability mean 0.4184，gate Brier 0.1388。
- threshold 0.5：TP=7、FN=11、TN=48、FP=0；precision=1.0、recall=0.389。
- nominal-to-teacher L1 为 0.3710，recovery-to-teacher conditional L1 为 0.2339，净改善 0.1371。不能再引用旧日志中错误稀释后的 0.10。

## 在线结果

### Held-out normal task491 episode0

- nominal OFT：success，165 env steps。
- V4.2 threshold 0.5：success，165 env steps。
- 21 decisions，0 triggers；gate probability 约 0.045--0.052。
- 每个未触发 decision 都通过 exact-hidden-bypass 检查，两条轨迹一致。

### Held-out recovery source task504 fork-55

- 从 canonical nominal rollout 精确重放 55 actions，再分别启动 paired policy。
- nominal：300 steps 内失败。
- threshold 0.5：最高 probability 0.216，无触发，失败。
- threshold 0.1：第 8 env step 触发一次 correction，随后 probability 降到约 0.05，300 steps 内仍失败。
- threshold 0.05、原 residual scale 0.1：触发 7 次，仍失败。
- 离线 residual-scale 扫描在 0.20 最优（L1 0.2178）；使用 threshold 0.05、scale 0.20 在线触发 12 次，仍失败。

因此目前已经证明 normal preservation，但还没有证明 recovery success。离线 action imitation 有明确改善，在线却无法完成恢复；当前失败集中在 recovery 数据覆盖和闭环 action effectiveness，而不是 online plumbing 或 nominal bypass。继续只调 threshold 或推理期 residual scale 已无价值。

## 下一步（按优先级）

1. 扩增独立 recovery forks。3 个 recovery sources 不足以判断跨来源泛化，下一轮至少保证 train / validation / test 各有多个 recovery physical sources。
2. 重训 residual adapter，并把 scale 0.20 作为训练时配置；在线不能靠事后放大替代对应分布上的训练。
3. 若扩数据和 scale-matched 重训后 frozen decoder 仍无法复现 teacher 闭环，再按 `v4_2.md` 做 decoder LoRA ablation。
5. 在多个 held-out normal episodes 和多个真实 failure forks 上跑 paired online matrix，再固定部署 threshold。
6. 主模型成立后再跑 `global / slot / relation_2d / relation_3d` controlled representation ablation，作为创新性证据；当前不应抢在 recovery success 之前做。
