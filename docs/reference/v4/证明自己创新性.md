对，**SlotVLA 的威胁很大，而且现在不止 SlotVLA**。我查了最近工作以后，结论比之前更严格：

* SlotVLA：object slots + relation tokens → 通用 action decoding。([arXiv][1])
* TriRelVLA：已经显式做 **object–hand–task relational graph**，并用 task-guided cross-attention 做 action generation。([arXiv][2])
* POT-VLA：已经做到 **role-aware 3D object tokens + target/destination/gripper relations + action conditioning + verification/recovery**，而且是真实 Unitree G1。([arXiv][3])
* ReCoVLA：已有 frozen VLA + failure-conditioned residual recovery。([arXiv][4])
* EgoRecovery：已有 gated recovery-specific corrective pathway。([arXiv][5])

所以我现在认为，下面这个故事**不能作为主要创新**：

[
\boxed{\text{Slot}\rightarrow\text{3D Relation}\rightarrow\text{Recovery Adapter}}
]

因为 reviewer 完全可以说：

> SlotVLA/TriRelVLA 已经做 relation-conditioned control，POT-VLA 已经做 3D relational recovery，你只是把这些东西接到 OFT 上。

这是真实风险。

---

# 一、我们需要换一个层次讲故事

我认为最有希望的定位不是：

> **“我们提出一种新的 object-relation representation。”**

而是：

[
\boxed{
\textbf{Object relations are a recovery interface for retrofitting frozen VLAs.}
}
]

核心问题变成：

> **如何在不重新训练一个强 nominal VLA、不破坏正常能力的情况下，只针对 off-nominal relational errors 添加 recovery capability？**

也就是：

```text
              已训练好的 OFT
                    │
          nominal behavior 很强
                    │
        ┌───────────┴───────────┐
     正常状态               failure state
        │                       │
     原 OFT               relation recovery
        │                       │
        └───────────┬───────────┘
                    ▼
                  action
```

我们不是提出另一个 general relational VLA。

我们研究的是：

[
\boxed{
\text{Post-hoc Recovery Adaptation}
}
]

这和 SlotVLA/TriRelVLA 的问题定义就不同。

---

# 二、但仅仅这样还不够，因为 ReCoVLA/EgoRecovery 也有 recovery adapter

所以真正需要证明的命题应该再进一步：

[
\boxed{
\textbf{For failure recovery, relational state is a better corrective interface than the VLA's global latent state.}
}
]

这句话非常关键。

不是：

> relations 有用。

这个别人已经证明过。

而是：

> **在 frozen VLA 已经失败、进入 off-nominal state 后，显式 task-conditioned robot–object relations 比原 VLA global feature 更适合作为 corrective residual 的输入。**

这才是我们的科学问题。

---

# 三、论文真正应该做一个“Controlled Recovery Representation Study”

我觉得这个反而可能成为论文最强的部分。

保持：

* 同一个 frozen OFT；
* 同一份 recovery data；
* 同一个 adapter 参数量；
* 同一个 Gate；
* 同一个 action decoder；
* 同样训练步数。

**唯一改变 recovery adapter 看什么表示。**

### Baseline A：Global Recovery

[
C_t=H_t^a
]

即：

> 直接使用 OFT 自己的 latent feature recovery。

回答：

> 普通 VLA representation 能不能自己解决？

---

### Baseline B：Slot Recovery

[
C_t=
CrossAttn(H_t^a,Z_t,Z_t)
]

回答：

> object decomposition 是否有价值？

---

### Baseline C：2D Relation Recovery

[
C_t=
CrossAttn(H_t^a,R_t^{2D},R_t^{2D})
]

例如：

* relative pixel center；
* overlap；
* mask relation。

回答：

> relation 是否比 object identity 更重要？

---

### Ours：Robot-centric 3D Relation Recovery

[
\boxed{
C_t=
CrossAttn(H_t^a,R_t^{3D},R_t^{3D})
}
]

其中：

[
R_t^{3D}
========

{
r^{gripper,target},
r^{target,goal},
r^{gripper,obstacle},...
}.
]

回答：

> corrective control 是否真正受益于 physically grounded relations？

---

如果最后是：

[
Global < Slot < 2DRelation < 3DRelation
]

这才是一条很有力的证据链。

不是证明：

> “我的模块很多所以厉害。”

而是证明：

[
\boxed{
\text{Recovery performance improves as the representation becomes more directly aligned with corrective control.}
}
]

---

# 四、但我认为还需要一个比普通 success rate 更强的实验

这是我现在最想加的：

# **Relation-Controlled Recovery Test**

不要只是随机跑 LIBERO-Plus。

人为控制：

[
\boxed{\text{只改变 relation，其他因素尽可能保持不变}}
]

例如同一个场景：

```text
              book
               │
        ┌──────┼──────┐
        │      │      │
      -4cm    0cm    +4cm
        │      │      │
      left   center  right
```

人为改变：

[
\Delta x_{g,target}
]

例如：

[
-6,-4,-2,+2,+4,+6\text{ cm}.
]

然后看 recovery action：

[
\Delta x_{action}.
]

如果你的模型真正读懂了 relation，应该出现：

[
\boxed{
\Delta x_{g,target}<0
\Rightarrow
\Delta x_{action}<0
}
]

和：

[
\boxed{
\Delta x_{g,target}>0
\Rightarrow
\Delta x_{action}>0.
}
]

而且随着偏移增大，corrective action magnitude 应该发生合理变化。

这比单纯：

> success rate 从 50% 到 70%

更能证明你的方法。

# 五、再做一个 Counterfactual Relation Test

这个我觉得尤其适合说服 reviewer。

保持：

* instruction 不变；
* object appearance 不变；
* background 不变；
* camera 不变。

只 swap relation：

```text
Case A

gripper   ketchup
    G -------- K

Case B

ketchup   gripper
    K -------- G
```

理论上：

[
A_A^{recovery}\neq A_B^{recovery}.
]

然后看：

### Global Adapter

是否对这种 controlled geometry shift 敏感？

### Slot Adapter

是否有所改善？

### Relation Adapter

是否能够稳定产生相反 correction？

如果结果很清楚：

[
\boxed{
\text{Relation representation induces predictable corrective behavior}
}
]

这个 evidence 很强。

---

# 六、再做 Language-Relation Grounding Test

因为前面你提的这个问题非常重要：

> 场景很多物体，为什么知道应该看 ketchup 和 basket？

这个也不能只展示 attention 图。

做 controlled experiment。

同一场景：

```text
ketchup
bowl
cup
basket
plate
```

改变 instruction。

### Instruction A

> Put ketchup into basket.

应该：

[
Attention(r^{gripper,ketchup})\uparrow
]

[
Attention(r^{ketchup,basket})\uparrow
]

---

### Instruction B

> Put cup into bowl.

应该：

[
Attention(r^{gripper,cup})\uparrow
]

[
Attention(r^{cup,bowl})\uparrow.
]

而 scene 不变。

这样可以证明：

[
\boxed{
\text{Relation selection is task-conditioned rather than purely geometric.}
}
]

这个实验比单纯可视化 attention map 强很多。

# 七、3D Relation 还必须证明 viewpoint robustness

否则 reviewer 会继续问：

> 你这个 3D relation 真正解决了什么？

做相同物理 state：

[
X^{world}
]

不同 camera：

[
C_1,C_2,C_3.
]

RGB完全变：

[
I^{C_1}\neq I^{C_2}\neq I^{C_3}.
]

但 robot-frame relation 应该：

[
\boxed{
R_{C_1}^{3D}
\approx
R_{C_2}^{3D}
\approx
R_{C_3}^{3D}.
}
]

然后比较：

| 表示              | Camera shift recovery |
| --------------- | --------------------: |
| Global          |                    xx |
| Slot            |                    xx |
| 2D Relation     |                    xx |
| **3D Relation** |                **xx** |

如果只有 3D relation 保住了 recovery：

这时候你才真正证明：

> 3D不是装饰。

# 八、“为什么不一直用 Relation？”也要变成核心实验

这个问题现在我认为已经不是 supplementary ablation，而应该进主表。

比较：

### Normal OFT

[
A_t=D(H_t)
]

### Always-on Relation

[
A_t=
D(H_t+\Delta H_t)
\quad\forall t
]

### Gated Relation Recovery

[
A_t=
D(H_t+g_t\Delta H_t).
]

测：

| Method             | Nominal | Recovery | Overall |
| ------------------ | ------: | -------: | ------: |
| OFT                |         |          |         |
| Always-on Relation |         |          |         |
| **Gated Relation** |         |          |         |

我们希望：

[
SR_{nominal}^{Gated}
\approx
SR_{nominal}^{OFT}
]

同时：

[
SR_{recovery}^{Gated}

>

SR_{recovery}^{OFT}.
]

如果 Always-on 在 nominal 上下降，那么故事成立：

[
\boxed{
\text{Recovery-specialized relation adaptation should not perturb nominal behavior.}
}
]

这也正好与 EgoRecovery 对 recovery-specific pathways 的动机形成呼应，但我们的 specialization 是**关系状态接口**。([arXiv][5])

# 九、还要直接和 SlotVLA 对打什么？

不一定必须完整复现 SlotVLA，但至少要有一个非常接近它思想的 baseline：

[
\boxed{\text{Always-on Slot/Relation Policy}}
]

因为 SlotVLA本质就是：

[
Object/Relation Tokens
\rightarrow
Action
]

作为 general visuomotor representation。([arXiv][1])

我们的对比要回答：

> “为什么不照 SlotVLA 一样，把 object-relation representation 全程用于 policy？”

如果 gated recovery：

1. normal performance 保持得更好；
2. recovery performance 更好或相当；
3. recovery-specific data 更少；
4. 不需要重新训练 nominal VLA；

那差异就非常明确：

### SlotVLA

[
\boxed{
\text{Learn a relational VLA}
}
]

### Ours

[
\boxed{
\text{Retrofit relational recovery onto an existing VLA}
}
]

这是两个不同问题。

# 十、POT-VLA 是目前更危险的 threat

这个必须特别提醒你。

POT-VLA 已经有：

* role-aware task objects；
* RGB-D → robot-frame 3D；
* target/destination/gripper relations；
* relation-conditioned action；
* geometric verification；
* failure recovery；
* real Unitree G1。

而且它明确报告 object-token conditioning + predicate recovery 的 ablation。([arXiv][3])

所以我们千万不要 claim：

> first 3D object-relational recovery for VLA.

大概率站不住。

---

# 十一、面对 POT-VLA，我们应该强调什么差异？

我觉得是：

### POT-VLA

是一个：

[
\boxed{\text{explicit structured execution system}}
]

需要：

* typed subtask；
* role-indexed TARGET / DESTINATION 等；
* SAM3 grounding；
* RGB-D object records；
* predefined geometric predicates；
* thresholds；
* failure handlers。

这些在论文方法里都是明确组件。([arXiv][3])

---

### 我们理想上应该是

[
\boxed{
\text{learned task-conditioned relational recovery}
}
]

不要提前人工指定：

```text
TARGET = slot 3
DESTINATION = slot 7
predicate = distance < 4cm
```

而是：

[
H_t^a(\text{language})
]

从 candidate relations 中**软选择** task-relevant relations，然后直接通过 recovery BC 学 corrective action。

也就是说我们的故事可以是：

> **We avoid manually specified task roles and recovery predicates; instead, the frozen VLA's language-conditioned action representation retrieves the relational evidence required for corrective action.**

这个差异我认为值得保留。

---

# 十二、如果要让这篇论文真正有说服力，我会要求六块证据

不是要求你实验越多越好，而是每块回答一个 reviewer question：

| 证据                             | 回答的问题                       |
| ------------------------------ | --------------------------- |
| **Global vs Slot vs Relation** | 为什么需要 relation？             |
| **2D vs 3D Relation**          | 为什么需要几何 grounding？          |
| **Instruction swap**           | 怎么知道哪个 object relation 重要？  |
| **Controlled relation shift**  | action 是否真的随 relation 改变？   |
| **Always-on vs Gated**         | 为什么 relation 不全程启用？         |
| **Recovery SFT vs Ours**       | 是结构有用还是只是 recovery data 有用？ |

如果这些证据全部成立，论文的说服力会比单纯加一个复杂 architecture 强很多。

---

# 十三、我会怎么重新写论文的核心 claim

不要写：

> We propose an object-relation-centric VLA for recovery.

和 SlotVLA 太近。

我会往：

[
\boxed{
\textbf{Relational Recovery as a Post-hoc Interface for Frozen VLAs}
}
]

去。

论文 observation：

> **Off-nominal manipulation often requires localized corrections to task-relevant robot–object relations, while the nominal VLA already provides a strong task policy.**

因此：

> **Rather than relearning the entire policy with structured representations, we selectively expose task-conditioned 3D relations to a lightweight recovery adapter only when correction is required.**

重点是：

[
\boxed{
\text{recover the VLA}
\neq
\text{replace the VLA}.
}
]

## 我目前对创新性的判断

如果只做到：

[
Slot+3DRelation+Gate+Adapter
]

我仍然会担心 reviewer 说“SlotVLA + EgoRecovery/ReCoVLA 的组合”。

但如果论文同时做到：

[
\boxed{
\text{新的 recovery representation hypothesis}
+
\text{极简 post-hoc architecture}
+
\text{controlled causal-style relation experiments}
}
]

尤其证明：

[
Global < Slot < 3DRelation
]

且：

[
\text{relation changes}\Rightarrow\text{predictable corrective action changes},
]

再证明 Gated 能保持 OFT nominal capability，那么**即使网络结构不复杂，论文也会有一个清晰的 scientific finding**：

> **Task-conditioned physical relations form an effective interface for adding recovery to pretrained VLAs without rewriting their nominal policy.**

我认为这才是面对 SlotVLA、TriRelVLA、POT-VLA 时最有机会站住的位置。
