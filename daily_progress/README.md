# 每日研发记录

本目录用于记录 Embodied-SlotSSM 复现与 Failure-Aware 扩展的每日进度。

文件命名统一使用北京时间日期：

```text
YYYY-MM-DD.md
```

每份日报至少包含：

1. 当日目标；
2. 完成的工程与实验；
3. 关键定量结果；
4. 当前在总路线中的位置；
5. 遇到的问题、已解决问题和遗留风险；
6. 模型、数据、日志与代码路径；
7. 下一步任务及验收标准。

日报中的“跑通”“训练完成”和“方法有效”需要严格区分：

- 跑通：程序和数据链路能够完整执行；
- 训练完成：达到计划训练步数并保存 checkpoint；
- 方法有效：在独立评测和必要消融中达到预先定义的验收标准。
